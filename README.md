# ShapeSonic 2D

A browser demo of [ShapeSonic: Sonifying Fingertip Interactions for Non-Visual Virtual Shape Perception (Huang, Hanocka, Siu, Gingold 2023 SIGGRAPH Asia)](https://cragl.cs.gmu.edu/shapesonic/) reduced to 2D. A shape is hidden on the screen. The user explores it with several fingers on a touchscreen, or with the mouse button, and hears where it is.

Try it [here](https://yig.github.io/ShapeSonic2D/).
